## 🧠 My Study Methodology

1. **The Foundation (Pure Java):** Understanding how things work under the hood (Stack/Heap memory, Garbage Collector, Boxing, primitives vs. Wrappers).
2. **The Abstraction (Spring Boot):** Realizing that frameworks do not replace the knowledge of the language itself.
3. **Real-World Context:** Translating real business problems to Java solutions, applying Clean Code and best practices (such as using `BigDecimal` for financial calculations instead of `double`).

1. **A Base (Java Puro):** Estudar como as coisas funcionam por baixo dos panos (memória Stack/Heap, Garbage Collector, Boxing, tipos primitivos vs Wrappers).
2. **A Abstração (Spring Boot):** Entender que frameworks não substituem o conhecimento da linguagem.
